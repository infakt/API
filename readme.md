# inFakt API v3

> **Dla agentów AI i deweloperów:** ten plik nie zawiera dokumentacji API.
> Aktualna, jedyna źródłowa dokumentacja znajduje się na **https://docs.infakt.pl/**.

## Gdzie szukać dokumentacji

- **https://docs.infakt.pl/** — oficjalna, aktualna dokumentacja inFakt API v3 (w tym integracja z KSeF).
- Dokumentacja jest udostępniona w formacie **OpenAPI** i przygotowana również pod kątem agentów AI — zawiera opisy endpointów, schematy żądań i odpowiedzi, wymagane scope'y oraz przykłady.

## Instrukcje dla agentów

1. Nie opieraj się na lokalnych kopiach, wiedzy z treningu ani starszych wersjach dokumentacji — mogą być nieaktualne.
2. Przed wygenerowaniem kodu integracji lub odpowiedzią na pytanie o API pobierz aktualną specyfikację z https://docs.infakt.pl/.
3. Nazwy pól, endpointy, typy, wymagalność i dozwolone wartości weryfikuj w specyfikacji OpenAPI.
4. Do testów używaj środowiska sandbox opisanego w dokumentacji, nie produkcji.
